PRACHI GAUR LOCAL WEBSITE - SMALLER DOWNLOADS

1. Download Prachi_Core.zip and all 6 Prachi_Images ZIPs.
2. To include videos, also download all 4 Prachi_Videos ZIPs.
3. Extract EVERY ZIP into the EXACT SAME destination folder.
   They all contain one folder named Prachi_Gaur_Local_Website. Merge it.
4. Open Prachi_Gaur_Local_Website/index.html in your browser.

The core ZIP is deliberately small to test whether downloads work at all.
The core alone contains HTML, styles, scripts and fonts; it needs the image
packs to display artwork. Each pack is an ordinary independent ZIP: no special
joining tool or software is needed. Original image and video files are preserved.
The earlier two large ZIPs are not required with these smaller packs.

This contact form cannot send messages. The interactive 3D viewer is online only.
Local references, image files and MP4 files were checked. Browser rendering and
offline interaction/playback were not tested because local-file navigation was
blocked by the available browser's security policy.
